# OPC

One person company workspace.

Current focus: AI Agent/MCP Security Gateway.

## Goal

Build open-source projects that can create trust, attract users, and convert into short-term cash flow through audits, setup services, hosted products, and enterprise support.

## Working Principle

- Open source is the acquisition channel, not the whole business.
- Start with narrow, painful problems where buyers can approve small budgets quickly.
- Sell services before building a full SaaS.
- Turn repeated service work into product features.

## Folder Structure

- `mcp-guard/`: main product repo with CLI, website, docs, tests, GitHub Pages, and npm package metadata.
- `mcp-guard-action/`: dedicated Marketplace action repo exported from `mcp-guard/dist/mcp-guard-action/`.
- `mcp-guard-demo/`: public demo repo and intentional failing PR for the GitHub Action.
- `docs/business/services/`: service ideas and prioritization.
- `docs/business/planning/`: original project planning notes.
- `docs/business/templates/`: reusable planning templates.

## Current Bet

AI teams are adopting agents and MCP quickly, but security, permissions, secrets, and auditability are still messy. A focused open-source gateway/scanner can win developer trust, while paid audits and managed monitoring can create early revenue.

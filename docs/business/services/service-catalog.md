## Selection Criteria

- Can be explained in one sentence.
- Has a painful, current problem.
- Has a buyer who can pay without a long procurement cycle.
- Can be useful as open source within one week.
- Has a natural paid layer beyond the free repo.

## First Project

AI Agent/MCP Security Gateway is the first project because it combines:

- strong market timing around agents and MCP;
- clear security anxiety;
- good open-source distribution potential;
- obvious paid services: audit, hardening, monitoring, private deployment.

Review MCP tool risk before your agent gets the keys.

mcp-guard is a local-first CLI that scans MCP and AI agent tool configs for risky shell access, unpinned packages, broad filesystem scope, exposed secrets, and remote MCP servers.

Built for the configs teams actually ship

Startup commands

Flags shell wrappers, interpreter eval modes, curl-pipe-shell, sudo, and destructive command patterns.

Supply-chain drift

Highlights npx, uvx, bunx, pnpm dlx, and unpinned MCP packages that can change underneath you.

Credential exposure

Detects secret-like environment variables and headers, then redacts values in generated reports.

Filesystem blast radius

Warns on root, home, Desktop, Documents, Downloads, and other broad local paths.

Local-first by default

MCP configs can expose private paths, hostnames, tokens, and internal workflow details. mcp-guard runs locally, avoids external API calls, and produces text, Markdown, or redacted JSON output.
